# 📊 تقرير أداء المصنع

تطبيق ويب تقدّمي (PWA) باللغة العربية لعرض التقرير الشامل لأداء المصنع، بتصميم متجاوب يدعم الوضع الداكن واتجاه RTL، ويعمل دون اتصال بعد التحميل الأول.

🔗 **الرابط المباشر:** https://ayad-mounir.github.io/factory-report/

## المزايا

- واجهة عربية كاملة (RTL) مع دعم الوضع الداكن تلقائيًا
- قابل للتثبيت على الهاتف والحاسوب كتطبيق مستقل
- يعمل بدون إنترنت عبر Service Worker
- ملف واحد مستقل (`index.html`) بلا اعتماد على خوادم خارجية

## هيكل المشروع

| الملف | الوظيفة |
|---|---|
| `index.html` | التطبيق الكامل |
| `manifest.webmanifest` | إعدادات التثبيت كتطبيق |
| `sw.js` | التخزين المؤقت والعمل دون اتصال |
| `*.png` | الأيقونات |

## التشغيل محليًا

```bash
python3 -m http.server 8000
```
ثم افتح `http://localhost:8000`

## النشر

يتم النشر تلقائيًا إلى GitHub Pages عند كل دفع إلى فرع `main` عبر `.github/workflows/pages.yml`.
